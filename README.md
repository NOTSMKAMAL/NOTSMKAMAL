## About Me 
I'm a third-year Computer Science student at UC Riverside with hands-on experience building production full-stack applications, mobile apps, and AI-powered systems. I've shipped 5+ web applications serving 5,000+ students, developed cross-platform mobile apps with React Native, and trained custom machine learning models for edge deployment. Through roles at ACM @ UCR, UC Riverside Admissions, and Design @ UCR, I've honed my skills in modern web frameworks, database management, API integration, and agile development. I'm passionate about building scalable, user-centered applications that solve real problems.
